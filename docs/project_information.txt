# Online Food Ordering System - Project Information

## Project Overview
This is a full-stack web application for an online food ordering system. It allows users to browse restaurants, view menus, place orders, and manage their accounts. The system includes user authentication, restaurant management, order tracking, and an admin panel.

## Technology Stack

### Backend
- **Runtime**: Node.js with ES6 modules
- **Framework**: Express.js
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT (JSON Web Tokens) with bcrypt for password hashing
- **CORS**: Enabled for cross-origin requests
- **Development**: Nodemon for hot reloading

### Frontend
- **Framework**: React 19.2.0
- **Build Tool**: Vite
- **Routing**: React Router DOM v7.9.5
- **HTTP Client**: Axios
- **Styling**: Bootstrap 5.3.8
- **Testing**: Jest with React Testing Library

## API Endpoints

### Authentication
- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `GET /api/auth/me` - Get user profile (requires JWT token)

### Restaurants
- `GET /api/restaurants` - Get all restaurants
- `GET /api/restaurants/:id/menu` - Get menu for specific restaurant

### Orders
- `POST /api/orders` - Place new order (requires JWT token)
- `GET /api/orders` - Get user's order history (requires JWT token)

## Data Models

### User
- name: String (required)
- email: String (required, unique)
- password: String (required, hashed)
- role: String (enum: "user", "admin", default: "user")

### Restaurant
- name: String (required)
- description: String
- address: String
- image: String

### FoodItem
- name: String (required)
- description: String
- price: Number
- image: String
- restaurant: ObjectId (reference to Restaurant)

### Order
- user: ObjectId (reference to User)
- items: Array of { foodItem: ObjectId, quantity: Number }
- total: Number
- status: String (default: "Pending")

#### Key Architectural Decisions

1. **State Management**: Use React Context API for global state (auth, cart)
   - AuthContext: Handle user authentication state and token management
   - CartContext: Manage shopping cart items and totals
   - RestaurantContext: Cache restaurant and menu data

2. **Routing**: React Router with protected routes
   - Public routes: /, /login, /register
   - Protected routes: /dashboard, /restaurants, /cart, /orders
   - Admin routes: /admin (role-based access)

3. **API Layer**: Centralized API service functions
   - Axios interceptors for JWT token handling
   - Error handling and response transformation
   - Base URL configuration

4. **Component Organization**: Feature-based folder structure
   - Group related components together
   - Separate page components from reusable components
   - Custom hooks for business logic

5. **Styling**: Bootstrap with custom CSS
   - Use Bootstrap utilities and components
   - Custom styles for branding and specific components
   - Responsive design principles

## Development Setup

### Backend Setup
1. Install dependencies: `npm install`
2. Create `.env` file with:
   ```
   MONGO_URI=mongodb://localhost:27017/food-ordering
   JWT_SECRET=your-secret-key
   PORT=5000
   ```
3. Start MongoDB
4. Run development server: `npm run dev`

### Frontend Setup
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Open http://localhost:5173
